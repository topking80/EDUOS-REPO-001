Verify a credential

Checks the school's digital signature and whether the credential is still valid.

Check a credential file

Paste the JSON of an Open Badges 3.0 credential you were given.

What this check shows

Only the achievement, the school, the date, and the learner's name if the learner chose to show it. Nothing else about the learner is shared here.

Format: W3C Verifiable Credential 2.0 / Open Badges 3.0 with an eddsa-jcs-2022 proof. This is a partial profile: it is not 1EdTech-certified, has no status list, and the school checks revocation live.
