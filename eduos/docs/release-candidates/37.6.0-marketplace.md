# 37.6.0 candidate: District marketplace

- Vendor listings with a district privacy review. Approval needs every
  checklist item, including no tracking, facial recognition or biometrics.
- Principals and teachers see only privacy-approved listings and request them
  through the existing `app_requests` queue.
- District approval reuses the existing licensing (app → district license →
  assignment). A trigger refuses approval while the privacy review is not
  approved or the DPA has expired.
- Fee hook placeholder: records a deferred fee event only (no amounts, no
  payments).
- Migration `061_marketplace.sql` (renumber if 051-057 land first). No new
  settings. Permissions reuse `apps:*`.
- Tests: `test/marketplace-37.6.test.js`, `test/integration/marketplace.test.js`.
  See `docs/MARKETPLACE.md`.
