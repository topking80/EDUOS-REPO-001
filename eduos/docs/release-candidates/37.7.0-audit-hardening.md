## Open decisions

  PayPal, Square and BTCPay sandboxes while a database transaction is open
  (idempotency keys make retries safe, but a slow provider holds a pool
  connection). Moving the call outside the transaction (reserve, commit,
  call, then record) is recommended before it merges.
- **37.7.1 version.** Merging the 37.7.1 notes without bumping the package to
  37.7.1 will fail `test/release-version.test.js`, on purpose.
