# Roku channel artwork

Put the final PNG files here with these exact names and sizes. The build uses
them in place of its plain placeholders, which are fine for sideloading but
not for publishing.

| File | Size (px) | Where Roku shows it |
| --- | --- | --- |
| `channel-poster_hd.png` | 336 x 210 | Home screen tile (HD) |
| `channel-poster_fhd.png` | 540 x 405 | Home screen tile (FHD) |
| `splash_hd.png` | 1280 x 720 | Launch screen (HD) |
| `splash_fhd.png` | 1920 x 1080 | Launch screen (FHD) |

The Roku Channel Store also asks for store artwork (screenshots and a poster)
when the channel is submitted; that's uploaded in the Developer Dashboard, not
kept here.
